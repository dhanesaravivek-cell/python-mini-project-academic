# Python Mini Project

## Project Title

Rainfall Analysis System

## Problem Statement

To analyze rainfall observations over several months, identify seasonal patterns, and compare rainfall across different periods.

## Objective

To develop a Python application that stores rainfall records and provides analytical summaries and visual reports.

## Features

* Store and manage rainfall records.
* Search and filter records by date or location.
* Calculate total and average rainfall.
* Identify the highest and lowest rainfall observations.
* Compare rainfall across different periods.
* Generate charts and visual reports.

## Technologies Used

* Python
* Pandas (if used)
* Matplotlib (if used)
* File handling
